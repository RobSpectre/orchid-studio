# Studio control map

Use JSON `POST http://127.0.0.1:8765/command`, or `.venv/bin/orchid-studio request '{"command":"status"}'` from the project directory. Responses report `ok`, `queued`, `sent`, or `error`. Read current `status` and `capabilities` first. `queued` needs status/event confirmation; `sent` does not prove sound.

The same map is available from `command-help`; filter with `name`. This reference is generated by `scripts/build-control-reference.py` from the runtime catalog.

## Studio controls

| Control | API | Behavior |
| --- | --- | --- |
| Start on key | `key-start` | Arms loops and selected drums silently; fresh raw Chord note starts/resumes. Performed/Bass/CC and held-note repeats do not wake. Stop disarms. |
| Transport and Space | `perform`, `loop-start`, `beats-play`, `play`, `pause`, `resume`, `stop`, `panic` | Read status. Space resumes/pauses the shared transport; when stopped it starts loaded loops with the configured drum accompaniment and live voice. It works from selectors, sliders and buttons; text entry keeps spaces. API callers choose which start explicitly. |
| BPM dial / suggested beat BPM | `tempo`, `beats-list` | Suggested BPM is metadata; apply it explicitly with tempo. |
| Mixer / center pan | `mixer-set` | Seven channels; volume=0 silences, pan=0 centers. |
| Pistil sound / per-layer selectors / editor / destination | `sounds-list`, `layer-select`, `layer-preset`, `layer-editor`, `pistil-status` | Each loop card changes only its own slot and preserves notes; mixer destination picker passes an explicit slot. Factory map describes defaults, not edited current patches. |
| Perform dial / bank / rhythm / fine controls | `perform-options`, `perform-configure`, `perform-update` | Bank is navigation; use its mode ID. Every fine control is in settings_schema. |
| Play Along On/Off | `play-along` | Separate raw-chord voice, slot 6. |
| Loop record / cancel / mute / clear / undo | `loop-start`, `loop-record`, `loop-cancel`, `loop-mute`, `loop-clear`, `loop-undo` | See command prerequisites; explicit slot avoids selected-layer ambiguity. |
| Loop length / snap / count-in | `loop-configure` | bars, grid and count_in fields. |
| Loop step / rest / cursor | `loop-step` | Rest advances the client beat cursor without inserting a note; next loop-step supplies the new beat. |
| Start drums with loops | `loop-start` | Pass drums object to include; omit for none. Applies to new start, not pause/resume. |
| Save/open loops | `loop-export`, `loop-import` | API returns/accepts document. Agent writes/reads local JSON; file chooser itself is browser-only. |
| Drum selection / play / length / reload | `beats-list`, `beats-select`, `beats-play`, `drums-length`, `beats-load` | Shared clock, bar-quantized selection. |
| Drum editor copy/new / steps / accents / bars / lanes / swing | `beat-get`, `beat-edit`, `beat-save` | Draft transforms, explicit save. bar/step are 1-based. See beat_editor metadata. |
| Drum draft undo / export / import | `beat-edit`, `beat-get`, `beat-save` | Keep undo_document per edit, pop client history to undo. Export returned document to JSON; import via beat-save. Unsaved browser drafts are private to that tab and are not remotely readable. |
| Sample preview / upload / kit import | `sound-preview`, `sample-upload`, `kits-import`, `kits-list` | Read library IDs and licenses; no file chooser required. |
| Loop/drum visualizers and diagnostics | `status`, `beat-get`, `events`, `pistil-status` | status.looper.layers[].notes plus position; drums.sequencer plus document; native meters. Rendering is client-side. |
| MIDI input/channel / clock / Sound following | `perform`, `loop-start`, `play-along`, `clock-configure`, `sound-follow` | Exact input name; confirmed raw Chord channel 3; no hardware output. |

## Commands

### key-start

Arm loaded loops to wake on a fresh raw-chord note.

**Fields:** enabled:boolean; input/chord_channel/settings/drums as loop-start when stopped

**Behavior:** Starts armed at beat zero without count-in; paused loops resume at cursor. First note feeds Live Perform. Stop/panic disarm; enable again to rearm.

### status

Read transport, loops, sounds, routing, mixer and clock state.

**Fields:** none

**Behavior:** Read-only

### capabilities

Discover commands, Perform settings and control map.

**Fields:** none

**Behavior:** Read-only

### command-help

Read this command reference; omit name for all.

**Fields:** name?: command string

**Behavior:** Read-only

### sounds-list

Map 100 Pistil slots and installed drum samples.

**Fields:** none

**Behavior:** Read-only; factory descriptions are configuration-derived

### events

Read recent events after a cursor.

**Fields:** after?: event_id, default 0

**Behavior:** Read-only; inspect truncated and last_event_id

### perform-options

List all Perform modes, banks, rhythms and settings schema.

**Fields:** none

**Behavior:** Read-only

### perform-configure

Change defaults and the running looper monitor settings.

**Fields:** settings: partial capabilities.settings_schema

**Behavior:** Does not change an already-running standalone Perform; use perform-update

### perform

Start Live Perform, optionally with drums.

**Fields:** input: exact MIDI name; chord_channel: 1–16; output_channel?: 1–16; settings?: partial settings; drums?: {engine:"studio",beat,volume}

**Behavior:** Replaces current transport; routes to slot 5

### perform-update

Update running Live Perform.

**Fields:** settings: partial settings

**Behavior:** Requires running Perform; queued; verify perform_updated event

### play

Play a MIDI session through Live AU.

**Fields:** session: version-1 MIDI session; bpm?: 30–300; transpose?: -48–48; repeats?: 1–128

**Behavior:** Replaces transport; global BPM wins unless explicitly supplied

### demo

Play the built-in demonstration.

**Fields:** bpm?: 30–300; transpose?; repeats?

**Behavior:** Replaces transport

### tempo

Set global BPM for every sequencer and outgoing clock.

**Fields:** bpm: 30–300 (UI 60–200); transition_seconds?: 0–10, default 2

**Behavior:** Safe during playback; integrated Bézier ramp

### pause

Pause global playback and release notes.

**Fields:** none

**Behavior:** Requires playback; finish/cancel take first

### resume

Resume global playback.

**Fields:** none

**Behavior:** Requires paused/running transport; repress physical keys

### stop

Stop all sequencers and release voices.

**Fields:** none

**Behavior:** Preserves recorded loops and sounds

### panic

Stop and release all notes, pedals and drum tails.

**Fields:** none

**Behavior:** Preserves recorded loops and sounds

### quit

Shut down Studio cleanly.

**Fields:** none

**Behavior:** Export session first; in-memory loops are not auto-saved

### loop-configure

Set loop length, quantization and count-in.

**Fields:** settings: {bars?:1–16,grid?:0 / 0.25 / 0.5 / 1,count_in?:0–16}

**Behavior:** Stop loops; resizing requires empty layers

### loop-start

Play loops and monitor input; optional record slot and drums.

**Fields:** input; chord_channel; output_channel?; settings?; slot?:1–4; wait_for_key?:boolean (without slot); drums?:{engine:"studio",beat,volume}

**Behavior:** Omit slot for immediate playback; count-in applies only with a recording slot; omit drums for no accompaniment

### loop-record

Arm a layer on the next loop boundary.

**Fields:** slot:1–4; settings?: Perform settings

**Behavior:** Requires running loops; replaces that layer only after a completed nonempty take

### loop-cancel

Discard an armed/unfinished take.

**Fields:** none

**Behavior:** Preserves existing recorded notes

### loop-mute

Mute/unmute one loop layer.

**Fields:** slot:1–4; muted:boolean

**Behavior:** Available live

### loop-step

Insert a chord without timed physical input.

**Fields:** slot:1–4; beat; notes:[0–127] (1–16 notes); duration?:0.125+ beats, default 4; velocity?:1–127; settings?

**Behavior:** Stop loops; insertion must fit length; same settings within a layer

### loop-clear

Clear one layer or all four.

**Fields:** slot?:1–4; omit for all

**Behavior:** Playing/paused supported; blocked during takes; keeps sounds

### loop-undo

Undo/redo the latest take, step edit or clear.

**Fields:** none

**Behavior:** Stop loops first; one swap-based undo level

### loop-export

Return session document with loops, six sounds, mixer and drum document.

**Fields:** none

**Behavior:** Save returned document to a local file; does not bundle samples/song MIDI

### loop-import

Restore a saved session document.

**Fields:** document: loop-export.document

**Behavior:** Stop transport; native host required for included instrument states

### pistil-enable

Start/recover installed native Pistil host and drum rack.

**Fields:** none

**Behavior:** Stop playback; preserves licensed installation

### pistil-status

Inspect six AUs, meters, audio output and native errors.

**Fields:** none

**Behavior:** Read-only; meters do not prove audible sound

### layer-select

Choose destination of next hardware Sound report.

**Fields:** slot:1–6 (loops 1–4, Perform 5, Play Along 6)

**Behavior:** During take, selection stays on recording layer

### layer-editor

Open selected Pistil plugin editor.

**Fields:** slot:1–6

**Behavior:** Native host required; use Computer Use for controls inside plugin

### layer-preset

Recall a numbered Pistil sound on one voice.

**Fields:** slot:1–6; preset:1–100

**Behavior:** Native host; factory names from sounds-list; user slots vary

### mixer-set

Set independent volume/pan.

**Fields:** channel:layer-1 / layer-2 / layer-3 / layer-4 / drums / live / play-along; volume?:0–1.5; pan?:-1–1

**Behavior:** Native host; available live; pan=0 centers

### play-along

Enable/configure the sixth direct-play voice.

**Fields:** enabled:boolean; input?:exact name; chord_channel?:1–16; velocity_limit?:1–127

**Behavior:** Native host; plays while transport runs, including alongside loops/drums

### sound-follow

Enable/disable fresh hardware Sound-report following.

**Fields:** enabled?:boolean; input:exact name when enabling

**Behavior:** Independent of note routes; next fresh dial movement updates selected slot plus slot 6

### clock-configure

Configure virtual MIDI clock publication.

**Fields:** enabled:boolean; offset_ms?:0–500

**Behavior:** Stop transport first; 24 PPQN, Start/Stop/Continue, no hardware feedback

### beats-list

List drum arrangements, suggested tempos, vibe/tags, energy/density and best uses.

**Fields:** none

**Behavior:** Read-only

### beats-load

Reload the native sample rack.

**Fields:** none

**Behavior:** Stop transport

### beats-select

Choose drum arrangement without changing global BPM.

**Fields:** beat: catalog ID

**Behavior:** During playback queues for next Studio bar

### beats-play

Start drums without loop or Perform playback.

**Fields:** beat: catalog ID; bpm?:30–300; volume?:0–1.5

**Behavior:** Stop existing playback first

### drums-length

Crop/repeat arrangement to requested playback length.

**Fields:** bars: even integer 2–64, or null for source length

**Behavior:** Live change queues to next bar; does not rewrite saved beat

### beat-get

Return saved and playback-length-adjusted beat JSON.

**Fields:** beat: ID

**Behavior:** Read-only; document is saved source, playback_document includes length override

### beat-edit

Transform a draft without saving: clone/new, rename, resize, swing, lanes, steps and bars.

**Fields:** document OR beat: source; action: capabilities.beat_editor.actions; action-specific fields in beat_editor

**Behavior:** Returns document + undo_document; no library/playback mutation until beat-save

### beat-save

Validate/persist a beat document; also imports beat JSON.

**Fields:** document: orchid-beat version 1

**Behavior:** Selected playing beat updates next bar; clone ID to preserve original

### kits-list

List available sounds, kits and provenance.

**Fields:** none

**Behavior:** Read-only

### kits-import

Import local Hydrogen-compatible kit/archive.

**Fields:** path: local directory or archive

**Behavior:** Stop playback; single-sample unpitched kits

### sample-upload

Import a local PCM WAV as a drum sound.

**Fields:** name; data:base64 WAV; license?:text

**Behavior:** Stop playback; <=8 MiB WAV and <=30 seconds

### sound-preview

Play one drum sample.

**Fields:** sound: sample ID

**Behavior:** Stop transport; native rack must be loaded

### drums

Drum volume and legacy backend actions.

**Fields:** action; value?; strip?; see capabilities.drum_actions

**Behavior:** Prefer mixer-set for native volume/pan and Studio transport commands

## Drum draft operations

`beat-edit` takes either `beat` (saved source ID) or `document` (your current draft), plus `action`. It returns `document` and `undo_document`, without changing the library or playback. Call `beat-save` to publish. Bars/steps are 1-based. Keep your own undo stack; draft undo does not overwrite a saved beat until explicitly saved. Browser drafts are tab-local, so API editing does not inspect another unsaved browser draft.

- `clone`: new_id, name: new identity; preserve notes
- `new`: new_id, name: new identity with empty hits; uses source lanes and length
- `rename`: name
- `resize`: bars 1–64; repeats/crops source hits, UI normally uses even 2–64
- `swing`: swing 0–0.45
- `lane-add`: lane:{id,name,sound,gain,muted}
- `lane-set`: lane:lane ID; settings:{name?,sound?,gain?,muted?}
- `step`: lane:lane ID; bar; step; mode?:toggle|set|remove|accent; velocity?:0.01–1; probability?:0–1. Accent toggles .55/.9 and preserves existing timing.
- `clear-bar`: bar
- `copy-bar`: bar, target_bar (wrap next bar in client)
- `repeat-bar`: bar; replace every bar with this bar

Example: clone a saved beat, then add a kick without overwriting its source:

```json
{"command":"beat-edit","beat":"glass-house","action":"clone","new_id":"user-night-drive","name":"Night Drive"}
```

Use the returned `document` as input for later edits and `beat-save`. For a step, pass `action:"step", lane:"kick", bar:1, step:1, mode:"set", velocity:0.8, probability:1`. To undo, use the last `undo_document`. For full document fields, see the project `docs/DRUM_STUDIO.md`.

## Boundaries and local state

- The Studio API covers its controls and musical effects. Browser navigation, cursor positions, visual rendering, local file saving and unsaved draft history are client operations with the equivalents above.
- `layer-editor` opens the Pistil plugin. Individual controls inside the vendor plugin are not Studio API parameters; use Computer Use for them. This audit does not claim full Pistil synthesis-parameter automation.
- The API does not expose Orchid firmware/maintenance, physical key presses or arbitrary hardware MIDI output. Studio is the clock master.
- Six AU slots: loops 1–4, Perform 5, Play Along 6. Mixer keys use `live` for Perform and `play-along` for the direct voice.
- Save the complete `loop-export.document` before restarting. Samples and supplied song MIDI live separately under ignored `local/`; exports do not bundle those files.
- Set exact physical input and raw chord channel: this device was confirmed Performed 1, Bass 2, Chord 3. Never merge all streams.
