## Perform modes

These are Studio software modes, not claims of exact Orchid factory Perform behavior. All follow global BPM.

| API ID | Bank | Description |
| --- | --- | --- |
| `off` | classic | Play held notes together; no generated rhythm. |
| `strum` | classic | Sweep upward across held chord notes over spread_beats; sustain until release. |
| `strum2` | classic | Upward strum across the chord plus an octave above. |
| `slop` | classic | A strum with seeded timing variation; slop controls looseness. |
| `arp` | classic | Cycle upward through held notes at the note division; gate controls length. |
| `arp2` | classic | Cycle upward through chord notes across two octaves. |
| `pattern` | classic | Apply the selected repeating four-beat rhythm to held chord notes. |
| `harp` | classic | One upward sweep over harp_octaves; each note has a short gated lifetime. |
| `bloom` | melodies | Maj9 / #11 motifs over a I–vi–ii–V progression. Imaj9(#11) – vi9 – ii9 – V13; minor: i9 – VImaj9 – iv9 – V7(b9). Lowest held note is root; chord third chooses major/minor. |
| `orbit` | melodies | Dorian color, 3–3–2 accents and suspended turns. i9 – IV13 – i11 – V7sus→V; major input uses Imaj9 – IVmaj9 – Imaj9 – V. Lowest held note is root; chord third chooses major/minor. |
| `drift` | melodies | Sparse 3rd / 7th voice leading, with 9ths and anticipation. Imaj9 – iii7 – vi9 – ii9/V13; minor: i9 – IIImaj7 – VImaj9 – iv9/V7. Lowest held note is root; chord third chooses major/minor. |
| `spark` | melodies | Chromatic enclosures resolving into a ii–V–I line. Imaj9 – ii9 – V13(b9) – Imaj9; minor uses iiø7 – V7(b9) – i9. Lowest held note is root; chord third chooses major/minor. |
| `tide` | melodies | A lyrical arc with a borrowed minor iv and a soft resolution. I6/9 – IVmaj9 – ivm6 – Imaj9; minor: i6/9 – VImaj9 – ivm6 – i9. Lowest held note is root; chord third chooses major/minor. |
| `sunline` | hooks | A syncopated synth-pop hook, suspended colors and a soaring answer. Iadd9 – IVmaj7 – vi9 – V13sus→I; minor: i9 – iv9 – VImaj7 – V7→i. Lowest held note is root; chord third chooses major/minor. |
| `sidekick` | hooks | A punchy power-pop refrain with repeated notes and a borrowed-minor turn. I6 – IVadd9 – I6 – iv6/V→I; minor: i – VI – i – V7→i. Lowest held note is root; chord third chooses major/minor. |
| `electric` | hooks | A clipped minor-pop hook with chromatic pickups and a dominant snap-back. i(add9) – VImaj7 – i(add9) – V7(b9)→i; major chords select a major variant. Lowest held note is root; chord third chooses major/minor. |
| `bluehour` | hooks | A spacious ballad refrain with delayed resolutions and tender chromatic turns. Imaj9 – vi9/ii9 – Imaj9 – iv6/V7→I; minor: i9 – VImaj9/iv9 – i9 – V7→i. Lowest held note is root; chord third chooses major/minor. |
| `anthem` | hooks | A driving rock call, octave lift and a long, singable final answer. i7 – bVIIadd9 – VImaj9 – V7→i; major: I6 – Vadd9 – IVmaj9 – V7→I. Lowest held note is root; chord third chooses major/minor. |

## Pattern rhythms

The `pattern` setting matters only when `mode` is `pattern`.

| ID | Description |
| --- | --- |
| `pulse` | Full chord on each beat. |
| `offbeat` | Full chord on every offbeat eighth. |
| `backbeat` | Lowest note on beats 1 and 3, full chord on 2 and 4. |
| `tresillo` | Full chord with a 3–3–2 eighth-note grouping. |
| `shuffle` | Swing pairs in triplet timing, moving through chord notes. |
| `rising` | Ascending chord tones on eighth notes. |
| `falling` | Descending chord tones on eighth notes. |
| `pendulum` | Back-and-forth chord-tone sequence on eighth notes. |

## Timing, pitch and controls

- `step_beats` controls note division; `.5` is an eighth note, `.25` a sixteenth.
- `gate` controls rhythmic note duration; `spread_beats` controls strum/harp width; `harp_octaves`, `slop`, `seed` and `velocity_limit` affect their named functions. Bounds are in `capabilities.settings_schema`.
- Melodies and Hooks use the lowest held note as root, with major/minor variants. Orbit, Electric and Anthem default to minor on a single note; the others default to major.
- Songs retain the user-supplied snippets. Hold MIDI 60/C4 for source register; other keys transpose. Use `.5` division and gate `1` for source timing. Phrase lengths are exposed in metadata.
- The live installed sample catalog is available from `sounds-list.drum_sounds` / `kits-list`: sample name, kit, source path and license. Use `sound-preview` while stopped to audition.
